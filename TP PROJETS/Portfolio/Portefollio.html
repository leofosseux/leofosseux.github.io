Veille Technologique : COBOL

Projet : Découverte et Application d'une Technologie Historique – COBOL

Contexte : Dans le cadre de ma formation en BTS, j'ai exploré COBOL, un langage de programmation créé dans les années 1960 et toujours utilisé dans les systèmes bancaires, gouvernementaux et de gestion des entreprises. Ce projet m'a permis de comprendre l'importance des systèmes hérités et leur impact dans le monde professionnel actuel.

Objectifs :

  • Découvrir les bases de la programmation en COBOL.
  • Créer un programme fonctionnel qui reflète l'utilisation de COBOL dans des environnements professionnels.
  • Comprendre comment moderniser des systèmes existants en interfaçant COBOL avec des technologies modernes.

Réalisations :

  • Développement d'une application simple en COBOL pour gérer une base de données de clients fictive :
    • Gestion des informations clients (nom, prénom, solde).
    • Simulation de transactions bancaires (dépôts, retraits).
    • Génération de rapports simples.
  • Intégration avec Python pour démontrer la communication entre systèmes modernes et anciens.

Ce que j'ai appris :

  • L'importance des systèmes hérités dans les infrastructures critiques.
  • Les bases de COBOL, un langage structuré avec une syntaxe orientée business.
  • Comment les entreprises modernisent leurs outils tout en s'appuyant sur des technologies anciennes.

Technologies utilisées :

  • COBOL : Programmation de l'application.
  • Python : Création d'une interface simple pour interagir avec le programme COBOL.
  • Visual Studio Code : Environnement de développement.

Conclusion :

Ce projet m'a permis de découvrir une technologie historique tout en développant des compétences polyvalentes et en renforçant ma compréhension des défis de la modernisation informatique. Cela me prépare à aborder des problématiques complexes dans des environnements professionnels réels.
